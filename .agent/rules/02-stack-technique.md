# Stack Technique : Lab Git

## 1. Outils Fondamentaux
- **Git** : Version 2.x+ (CLI obligatoire).
- **GitHub CLI (gh)** : Pour les interactions avec GitHub.
- **Markdown** : Pour la documentation.
- **VS Code** : Éditeur recommandé (avec extensions Git Graph/GitLens si nécessaire).

## 2. Environnement
- **OS** : Windows (PowerShell/Git Bash) / Linux / macOS.
- **Terminal** : Utilisation intensive du terminal requise.

## 3. Contraintes
- **CLI First** : Privilégier les commandes terminaux aux interfaces graphiques pour l'apprentissage.
- **Convention de Commits** : Conventional Commits (feat, fix, docs, chore).

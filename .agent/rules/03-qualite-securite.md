# Qualité & Sécurité : Best Practices Git

## 1. Historique Git
- **Atomicité** : Un commit par changement logique.
- **Messages** : Clairs, impératifs (ex: "Ajouter la section X" pas "j'ai ajouté...").
- **Propreté** : Pas de fichiers inutiles (gestion du `.gitignore`).

## 2. Gestion des Conflits
- **Analyse** : Toujours comprendre la source du conflit avant de résoudre.
- **Vérification** : Tester le code après une résolution de conflit.

## 3. Documentation
- **Markdown** : Structure claire (Titres, Listes, Code blocks).
- **Rigueur** : Chaque atelier doit avoir son fichier de documentation associé.

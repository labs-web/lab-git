# Tutoriel : Simplifier la synchronisation des Skills (Aliases Git)

## Problème
Vous avez plusieurs skills (`init-lab`, `conception-agent`) et taper ces commandes à rallonge est pénible :
`git subtree pull --prefix .agent/skills/init-lab skills-lib branch-init-lab --squash`

## Solution : Les Alias Git
Nous allons créer des raccourcis simples pour mettre à jour tous vos skills d'un coup ou individuellement.

---

## 1. Créer vos raccourcis (Aliases)

Ouvrez votre terminal dans votre projet et copiez-collez ces commandes. Elles vont configurer votre Git local.

### Pour le skill `init-lab`
```bash
# Pour mettre à jour (PULL)
git config alias.pull-init-lab "subtree pull --prefix .agent/skills/init-lab skills-lib branch-init-lab --squash"

# Pour envoyer des modifs (PUSH)
git config alias.push-init-lab "subtree push --prefix .agent/skills/init-lab skills-lib branch-init-lab"
```

### Pour le skill `conception-agent`
```bash
# Pour mettre à jour (PULL)
git config alias.pull-conception "subtree pull --prefix .agent/skills/conception-agent skills-lib branch-conception --squash"

# Pour envoyer des modifs (PUSH)
git config alias.push-conception "subtree push --prefix .agent/skills/conception-agent skills-lib branch-conception"
```

---

## 2. Utilisation au quotidien

Maintenant, la vie est belle.

**Mettre à jour un skill :**
```bash
git pull-init-lab
git pull-conception
```

**Envoyer une correction :**
```bash
git push-init-lab
```

---

## 3. Le Niveau Supérieur : Tout mettre à jour d'un coup

Si vous voulez être le roi de l'efficacité, créez un alias qui lance tout en chaîne (sur Linux/Mac/Git Bash).

**Note :** Sur Windows PowerShell, c'est plus complexe, il vaut mieux faire un petit script `update-skills.ps1`.

### Script Windows (`update-skills.ps1`)
Créez ce fichier à la racine de votre projet :

```powershell
Write-Host "Mise à jour de init-lab..."
git pull-init-lab

Write-Host "Mise à jour de conception-agent..."
git pull-conception

Write-Host "Terminé !"
```

Lancez-le simplement : `./update-skills.ps1`

# Tutoriel : Synchroniser un Skill Agent Spécifique (Git Subtree Split)

## Contexte
Vous avez un dépôt central `agent-skills` contenant plein de compétences (`init-lab`, `conception-agent`...).
Dans votre projet actuel (`lab-git`), vous ne voulez importer **QUE** le dossier `init-lab`, sans tout le reste.

**La solution :** Utiliser la fonction **Split** de Git Subtree pour isoler ce dossier dans une branche dédiée.

---

## Etape 1 : Préparer le Dépôt Source (`agent-skills`)

*Cette étape se fait UNE SEULE FOIS sur votre dépôt bibliothèque.*

Nous allons créer une branche "orpheline" qui ne contient que les fichiers du dossier `init-lab` à sa racine.

1.  Placez-vous dans votre dépôt `agent-skills`.
2.  Créez la branche spécifique :

```bash
# Sépare le dossier 'init-lab' dans une nouvelle branche 'branch-init-lab'
git subtree split --prefix=init-lab -b branch-init-lab
```

3.  Envoyez cette branche sur GitHub :

```bash
git push origin branch-init-lab
```

> **Résultat :** Sur GitHub, vous avez maintenant une branche `branch-init-lab` qui ne contient que les fichiers de ce skill.

---

## Etape 2 : Importer dans le Lab (`lab-git`)

Maintenant, allons dans notre projet consommateur.

1.  Ajoutez le dépôt distant (si ce n'est pas déjà fait) :

```bash
git remote add -f skills-lib https://github.com/votre-user/agent-skills.git
```

2.  Ajoutez le skill à l'endroit voulu :

```bash
# On tire la branche SPÉCIFIQUE 'branch-init-lab'
git subtree add --prefix .agent/skills/init-lab skills-lib branch-init-lab --squash
```

> **Résultat :** Seul le dossier `init-lab` est ajouté à votre projet.

---

## Etape 3 : Mettre à Jour (Workflow Quotidien)

### Cas A : Le Skill a évolué ailleurs, je veux la mise à jour
Quelqu'un a amélioré `init-lab` sur le dépôt central.

```bash
git subtree pull --prefix .agent/skills/init-lab skills-lib branch-init-lab --squash
```

### Cas B : J'ai amélioré le Skill ici, je veux partager
Vous avez corrigé un bug dans `init-lab` localement.

1.  Commitez vos changements dans `lab-git`.
2.  Poussez vers la branche spécifique du dépôt central :

```bash
git subtree push --prefix .agent/skills/init-lab skills-lib branch-init-lab
```

---

## Résumé des Commandes (Antisèche)

| Action                | Commande                                                        |
| :-------------------- | :-------------------------------------------------------------- |
| **Isoler (Source)**   | `git subtree split --prefix=<dossier> -b <branche>`             |
| **Installer (Cible)** | `git subtree add --prefix <cible> <remote> <branche> --squash`  |
| **Update (Pull)**     | `git subtree pull --prefix <cible> <remote> <branche> --squash` |
| **Contribuer (Push)** | `git subtree push --prefix <cible> <remote> <branche>`          |
